## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Intuitive Ribbon-style Interface** — Navigate easily through project management tools and options.
- **Task and Subtask Creation** — Assign specific times and resources to tasks for efficient project oversight.
- **Task Dependencies** — Establish connections between tasks to enhance workflow management.
- **Gantt Chart Views** — Visualize the planned timeline for each task for better scheduling.
- **Basic PERT Chart Representation** — Understand relationships between various tasks easily.

- **Microsoft Project Compatibility** — Import and export projects seamlessly with Microsoft Project.
